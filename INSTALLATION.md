# Pre-built JAR Available

The compiled mod JAR is available in the releases section.

## Installation

1. Download `tiertagger-1.0.0.jar` from the releases
2. Locate your `.minecraft` folder
3. Create a `mods` folder if it doesn't exist
4. Drag and drop the JAR into the `mods` folder
5. Launch Minecraft with Fabric Loader

That's it! The mod will automatically fetch tier data from Xrawr when players join.
